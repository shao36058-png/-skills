# 合成效率、输入隔离与模式

## 先写端口关系

从物理端口面、电场方向及参考面确定输入、输出和差模通道。本文数字编号只属于相应案例。BJ140 为 15.80 × 7.90 mm，常规空气矩形波导的 TE10 截止约 9.487 GHz，TE20 与 TE01 均约 18.974 GHz；13.75–14.5 GHz 在均匀 BJ140 接口处仅 TE10 传播。

结区内仍可有高阶倏逝场，3D 全波场并未因为接口只提取 TE10 就忽略它们。截止模式不能作为独立远端功率出口计入效率。内部加宽后可能产生新的传播模，需要重新检查截面与端口模式。

E 面 T 在一致的模态极性下通常把两直臂的反相分量导向 E 支臂；H 面 T 对应同相的和分量。但输入弯头的布置和极化输运也参与外部相位关系。最终条件始终是有效输出中的两项 `S_out,1 a1` 与 `S_out,2 a2` 同相。不能仅凭模型俯视图或端口编号判断。

## 高效率为什么可以伴随差隔离

对功率波归一化且均为传播模的网络：

```text
b = S a
a_i = sqrt(P_i) exp(j phi_i)
eta = |b_out|² / (|a_1|² + |a_2|²)
I_12 = -20 log10 |S_21|              # 正值隔离度，越大越好
S_21_dB = 20 log10 |S_21|            # HFSS 常见负值曲线
```

独立隔离是在只有一个输入激励、其余端口匹配时测得的输入间耦合。双源工作时，输入返回波例如 `b1=S11*a1+S12*a2` 可以相消，输出波相加。因此正常同相效率接近 100%，仍可能有约 −6 dB 的单源串入另一功放。

理想对称、公共口匹配的无耗三端口等分网络，其两个输入的自反射和互耦幅度可各为 1/2，即约 −6.02 dB；平衡合成时返回可相消。这不是任意三端口的通用数值极限。严格约束是无耗、互易、单模三端口不能同时全匹配并隔离两输入。需要差模匹配出口、选择性吸收或其他物理机制。

旧 H-T 铜壁例的效率为 99.616–99.661%，最差隔离只有 5.884 dB；这两项计算并不矛盾。对照数据见 [案例目录](case-library.md)。

## 如何看 HFSS 曲线与源设置

线性材料、同一几何和边界下，修改 Edit Sources 的幅度或相位不改变 S 矩阵。S 是网络响应，合成输出是 `S a` 的相干叠加。更改源后无需为了得到新的 S 而重跑；若改了几何、材料、边界或负载模型，则要重新求解适用的网络。

选择完整复数 S 数据或相干功率/场报告查看总输出，不能把 `dB(S31)` 单独当作两源总输出。六条线可能来自多条表达式、多个几何 variation 或多个模式；检查图例、Families、源表达式和模式编号后才能解释。对名义几何固定所有独立变量，不用历史 variation 混画。

路径相位差可用 `angle(S_out,1/S_out,2)` 表示；它是两条传输路径的相位差，不是两个源的绝对相位。对预期反相的路径，用明确的 180° 误差表达式避免相位包裹误判。比值任一项为零时相位无定义。

在实数参考阻抗、RMS 功率波约定下，端口电压/电流满足 `V=sqrt(Z0)(a+b)`、`I=(a-b)/sqrt(Z0)`，电流方向取流入网络。不同峰值约定有常数因子，复数波导阻抗还需使用对应归一化。双源改变会改变活动电压、电流和 `V/I`；这不是把每个波导端口变成固定电阻。

## 隔离出口的终端是设计的一部分

0 W 波端口表示入射波为零，但出射波可以带走能量，相当于理想匹配终端。不能因为叫“隔离口”就要求在所有激励下功率为零。理想魔 T 的同相输入在差模口相消；单源、反相或失衡时，差模口应该接收功率。

若正常同相输入仍向辅助口送去 0.093 W / 总输入 1 W，应把它列为正常分流，而非从效率分母中删除。对应五端口实例隔离约 20 dB，但有效输出效率约 87–93%。

金属封闭出口相当于反射终端，不是仍保留 0 W 波端口。需重建边界求解，或在已有线性网络上用已知终端做网络缩并：

```text
a_L = Gamma_L b_L
S_eff = S_KK + S_KL (I - Gamma_L S_LL)^(-1) Gamma_L S_LK
```

`K` 是保留通道，`L` 是终止通道；所有矩阵参考面必须一致。标量负载回波损耗 `RL` 对应 `|Gamma|=10^(-RL/20)`。实际负载随频率变化，独立相位扫描只是敏感性包络，不是其真实频响。内部增加实体负载后，局部耦合发生变化时仍需全波验证。

新魔 T 的理想负载隔离为 24.383 dB；第 4 口 RL=20 dB 时，相位扫描最差约 19.158 dB。即使正常效率几乎不变，也不能继续声称实物隔离仍为 24 dB。

## 输出加宽、渐变和过模

输出截面与均匀段长度是两种自由度。端口太靠近不连续处可能影响模态提取，截面/结区不匹配也会造成反射；不能从“波被挡住”直接认定必须加长或加宽。内部加宽并渐变回 BJ140 需要同时审核匹配、隔离和模式。

28 × 7.9 mm 的过模输出例有 TE10 与 TE20 两个传播通道。三个几何接口对应四个模态通道：输入 1、输入 2、输出 TE10、输出 TE20。该例约 21.8 dB 隔离依赖未利用 TE20 的匹配终端。不能把有效 TE10 与差模 TE20 的功率都当作有效基模输出。

若接回 BJ140，TE20 在该截面截止，能量在渐变/反射过程中与整体网络相互作用。它不会自动变成 TE01；实际模式转换取决于过渡的对称性与几何。必须包含下游过渡和终端再评估。

## 离线输入与审核范围

`scripts/combiner_metrics.py` 需要 NumPy。格式示例（数组须覆盖所有频率，数据须含完整 N×N）：

```json
{
  "frequencies_GHz": [13.75, 14.5],
  "channel_order": ["1:1", "2:1", "3:1", "4:1"],
  "audit_config": {
    "input_channels": ["1:1", "2:1"],
    "output_channel": "3:1",
    "load_channels": ["4:1"],
    "powers_W": [0.5, 0.5],
    "phases_deg": [0, 0]
  },
  "data": {"S(1:1,1:1)": {"real": [0, 0], "imag": [0, 0]}}
}
```

上面只演示一个元素，不是完整可运行矩阵；完整例见 [魔 T 数据](../assets/cases/magic-t-equal-h-bends.json)。输入须是传播模的功率波 S；脚本无法仅凭数值确认归一化、截止状态和边界真实性。它审核频率网格、有限复数、互易性、最大奇异值及功率残余，并计算：

- 双源平衡、各单源、相对基准反相、第二源 ±10°/±20°，以及两源等功率为基准的 ±1 dB 失衡。
- 单源时保留该源原始功率，分母随之变化；“关闭”源的物理端口仍按匹配终端。
- 有效输出、返回两个输入、匹配负载功率及全部通道功率和的残余。残余包含导体/介质损耗与数值误差，不能全部叫铜耗。
- 可选的负载 RL 相位扫描，步进 2°。多个负载时只扫描它们的共同相位，不是各负载独立失配的全局最坏情况。

输入有效输出按一个模式指定；其他模式的功率单列。若用途需要多个有用输出，应明确重新定义效率，而不是改变隔离通道标签来美化结果。脚本的互易/无源容差为数值筛查，不能替代 HFSS 收敛或实际测量。

## 功率容量与故障

这些案例以总输入 1 W 归一化。线性 S 可用于小信号比例推算，但不能证明 1 kW 连续波安全。两路各 500 W 时，单路工作可能把约 250 W 导向理想差模负载；双路等幅反相可能把接近 1 kW 导向它。实际故障功放可能不是匹配终端，需加其反射模型。

至少分开评估正常工况导体/介质热耗、差模负载故障热耗、边缘峰值电场、圆角、空气/气压、接触、无氧铜温度与水冷热边界。腔体负体积模型中的柱形空洞若全部施加金属壁，是匹配柱占据的区域，不等同于外壳向空气开孔；实物贯通加工需有连续导电封接。

文献几何频率缩放可作初值，不能唯一反推出新频段的最优尺寸。频率比与指定波导截面比不一致时，尤其不能照搬全局比例。区分论文原始指标、本次全波结果、假设材料和经加工验证的实物。
