# BJ140 E-T 双膜片匹配案例：13.75–14.5 GHz

此案例将已有 E 面 T 形功分器改为 BJ140 截面，并按用户要求直接修改、保存原项目，没有另建工程副本。是否原位修改或另存副本由用户选择；本例不为其他任务设置强制复制或归档要求。文件名可能沿用旧频段，实际工作频段应从当前几何、设置及保存结果判断。

这里给出可复核的示例尺寸和已保存复数 S 参数，不能把它们作为其他波导、频段、加工条件的通用最优值或额定功率指标。共同坐标、膜片及模式相位定义见 [几何与电磁约定](et-design.md)。

## 最终几何及完整尺寸

采用空气腔、理想导体壁、对称双感性膜片。以下单位为 mm。宽边沿 x，横臂沿 z，输入支路沿 +y；`c` 是横臂总长，`d` 是从 T 结外壁 `y=b/2` 到输入端口的支路长度。

| 波导参数 | 数值 |
|---|---:|
| 宽边 `a` | 15.800 |
| 窄边 `b` | 7.900 |
| 横臂总长 `c` | 60.000 |
| 输入支路长 `d` | 30.000 |
| 空气腔整体 y 向跨度 `d+b` | 37.900 |
| 输入端口全局 y `b/2+d` | 33.950 |
| 两横臂端口全局 z | −30.000 / +30.000 |

| 膜片参数或派生量 | 第一片 | 第二片 |
|---|---:|---:|
| 中央开口全宽 `w_i` | 7.800 | 10.150 |
| 左右每侧伸入深度 `(a-w_i)/2` | 4.000 | 2.825 |
| 沿 y 厚度 `t_i` | 0.250 | 0.250 |
| 中心距 T 结外壁 `d_i` | 4.230 | 14.550 |
| 近面距 T 结外壁 `d_i-t_i/2` | 4.105 | 14.425 |
| 远面距 T 结外壁 `d_i+t_i/2` | 4.355 | 14.675 |
| 全局中心 y `b/2+d_i` | 8.180 | 18.500 |
| 全局近面 y | 8.055 | 18.375 |
| 全局远面 y | 8.305 | 18.625 |
| 开口 x 范围 | [−3.900, +3.900] | [−5.075, +5.075] |

两片都在 z 方向贯穿整个窄边，开口高度为 7.900 mm、z 范围为 `[−3.950,+3.950]`。中心间距 10.320 mm，相邻表面净距 10.070 mm，第二片远面至输入口 15.325 mm。膜片只从左右 x 壁对称伸入，不在中央开口中放置独立悬空金属片。

本例端口 2 为共同输入，端口 1、3 为反相等分输出。报告使用基模 `S(2:1,2:1)`、`S(1:1,2:1)`、`S(3:1,2:1)`；输出模式极性一致时相位差约 180°。检查别的工程时重新识别物理端口，不能默认编号相同。

## 为什么不能把 24 GHz 尺寸整体同比缩放

旧案例截面为 `a=10.668, b=4.318 mm`，新截面为 `a=15.800, b=7.900 mm`，宽边和窄边倍率分别约 1.4811 与 1.8296，长宽比已经改变。保留旧开口和位置会造成强失配；只按频率倒数把所有尺寸乘同一个比例，也不满足这些几何约束。

用中心频率的 TE10 导波波长作初值尺度：

```text
fc10 = c0/(2a)
lambda_g = (c0/f)/sqrt(1-(fc10/f)^2)
beta = 2*pi/lambda_g
```

旧例 24 GHz 的 `lambda_g≈15.4081 mm`；新例 14.125 GHz 的 `lambda_g≈28.6479 mm`，电长度倍率约 1.8593。将旧中心距离 `2.277/7.828 mm` 按此倍率估算，得到约 `4.234/14.554 mm`，据此取本例的 `4.230/14.550 mm` 作为初值并通过实际求解验证。

开口宽度还影响膜片电纳。薄对称感性膜片的一阶近似为：

```text
B/Y0 ≈ -(lambda_g/a)*cot^2(pi*w/(2a))
```

只保持 `w/a` 会让本例的 `lambda_g/a` 增大约 25.5%，从而改变电纳。按相同薄片电纳估计，新开口约为 `7.902/10.239 mm`。由于厚度仍固定 0.250 mm，未按电长度倍率变为约 0.465 mm，还需考虑有限厚度及结区近场；本例采用 `7.800/10.150 mm`，最终以 HFSS 实际保存结果为准。这套估算用于缩小搜索范围，不保证其他尺寸组合也取得同样性能。

对于本例截面，理想空波导截止频率为：

| 模式 | 截止频率 / GHz |
|---|---:|
| TE10 | 9.4871 |
| TE20、TE01 | 18.9742（简并） |
| TE11、TM11 | 21.2138 |
| TE30 | 28.4613 |

目标频带仅 TE10 传播；消逝高阶模仍可能影响不连续处近场。TE20 与 TE01 简并，求解器的模式序号可能交换，不能把“模式 2”在所有情况下固定解释为 TE20。

## 离线复核

在技能根目录执行，输出路径选择技能目录以外的工作位置：

```bash
python scripts/divider_metrics.py --input assets/bj140-14ghz-case.json --max-reflection-db -25 --min-frequency-ghz 13.75 --max-frequency-ghz 14.5 --output ../bj140-audit.json
```

脚本只读取 JSON 并计算指标，不连接 AEDT、不修改工程、不重新求解。若需要实际调参或保存工程，按 [AEDT 操作参考](aedt-workflow.md) 核实当前会话、名义几何与用户授权的编辑位置。
